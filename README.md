# 社会テスト対策クイズ

1920年代の大衆社会から世界恐慌、ファシズム、満州事変、日中戦争、第二次世界大戦、太平洋戦争、戦時下の生活、終戦までを扱う確認テストです。

## 特徴

- 全80問
- 四択・記述を混在
- 単元別に絞り込み
- 問題形式で絞り込み
- 10 / 20 / 40 / 全問から出題数を選択
- 四択は押した瞬間に採点
- 記述は入力後すぐ採点
- 各問題の解説に教科書ページを表示
- 間違えた問題だけ再挑戦可能
- 完全静的サイトなのでGitHub Pagesで動作

## GitHub Pagesで公開する方法

1. このフォルダ内の `index.html`, `style.css`, `questions.js`, `app.js` をGitHubリポジトリ直下へアップロード
2. GitHubの `Settings` → `Pages`
3. `Build and deployment` で `Deploy from a branch`
4. Branchを `main`、フォルダを `/(root)` にして保存
5. 数分待つと公開URLが表示されます

サーバーやビルド作業は不要です。

## 出典について

各問題の「教科書」表示は、ユーザーが送付した写真のページ番号をもとにしています。
主な範囲：

- 教科書①：p.108〜135
- 教科書②：p.220〜239
